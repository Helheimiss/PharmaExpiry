# PharmaExpiry

Система автоматизированного контроля сроков годности лекарственных средств для аптечных сетей. Проект реализует специализированную базу данных и клиентское приложение, обеспечивающие оперативный мониторинг партий препаратов с истекающим сроком хранения и визуальное предупреждение персонала о критических остатках.

## Описание проекта

Проблема реализации просроченной продукции в розничной фармацевтической торговле носит не только экономический, но и социальный характер. Существующие ERP-системы зачастую ориентированы на общий товарооборот и не предоставляют инструментов для оперативной визуализации приближающихся к пределу хранения позиций. Данное решение переносит логику контроля сроков годности на уровень структуры данных и пользовательского интерфейса, минимизируя влияние человеческого фактора.

Ключевые особенности системы:
*   **Партийный учет:** Фиксация даты производства, серии, номера партии и конечного срока годности для каждой единицы товара.
*   **Визуальная индикация:** Цветовое кодирование складских остатков в зависимости от степени приближения к дате истечения срока годности.
*   **Механизм раннего предупреждения:** Автоматическое выделение товаров, срок годности которых истекает в заданный интервал (например, 30 дней).
*   **Адресное хранение:** Поддержка иерархической структуры складов, аптек, зон хранения и ячеек.
*   **Целостность данных:** Строгая система ограничений целостности и каскадных операций на уровне СУБД.

## Технологический стек

*   **База данных:** Microsoft SQL Server (T-SQL)
*   **Backend / Логика:** C#, .NET 8
*   **Frontend / UI:** WPF (Windows Presentation Foundation), XAML
*   **Архитектура:** MVVM (Model-View-ViewModel)
*   **Контроль версий:** Git, GitHub
*   **Среда разработки:** Visual Studio 2022+

## Структура репозитория

*   `/db` — SQL-скрипты создания базы данных, таблиц, связей и ограничений целостности.
*   `/src` — Исходный код клиентского приложения WPF.
*   `/docs` — Документация, ER-диаграммы и описание предметной области.

## Быстрый старт

1.  Клонируйте репозиторий:
    ```bash
    git clone https://github.com/your-username/PharmaExpiry.git
    ```
2.  Создайте базу данных, выполнив скрипт из папки `/db` в среде SQL Server Management Studio.
3.  Откройте файл решения `.sln` из папки `/src` в Visual Studio.
4.  Укажите актуальную строку подключения к базе данных в конфигурационном файле приложения.
5.  Запустите проект для проверки работоспособности интерфейса и подключения к БД.
